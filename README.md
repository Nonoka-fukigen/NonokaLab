# Nonoka Lab

> 本地优先 · 插件化 · 桌面工具箱　|　**v1.0.0**

Nonoka Lab 是一个运行在 **Windows** 上的桌面工具箱，主打 **B站视频下载**。下载能力以**插件**形式提供，安装后即可使用，所有数据都保存在你自己电脑上，不收集任何数据。

下载（解析 + 保存）主链路已经跑通，架构为后续扩展其它平台预留了空间。

---

## ✨ 现在就做什么

**B站视频下载**：粘贴视频链接，一键下载——

- **视频**（可选清晰度增强）
- **音频**
- **视频 + 音频**（ffmpeg 合并）
- **封面**（支持 2x / 4x 放大）

配套能力：**任务队列**（多任务排队 / 暂停 / 恢复）、**下载历史**（搜索 / 删除 / 导出 CSV）、**系统托盘**后台运行、桌面通知。

> 🚧 **抖音**及更多平台为**开发中（coming soon）**，计划后续版本加入。

---

## ⚡ 快速开始（三步曲）

1. **下载**：从 [GitHub Releases](https://github.com/nonoka-lab/nonoka-lab/releases) 下载最新安装包 `NonokaLab_Setup_v1.0.0.exe`。
2. **安装**：运行安装向导，建议勾选 **FFmpeg 组件**（合并视频+音频时需要）。安装后从桌面启动。
3. **粘贴链接下载**：打开「视频下载」→ 粘贴 B站链接 → 点「解析」→ 选择`视频 / 音频 / 视频+音频 / 封面` →「下载」。

> 需要 Windows 10/11（自带 Edge WebView2）。

---

## 🪟 常用操作

- 启动后窗口不出现？程序在**系统托盘**后台运行，点击托盘图标即可打开。
- 关闭窗口 = 隐藏到托盘，**下载任务继续后台执行**；彻底退出请在托盘右键菜单选「退出」。

---

## ⚠️ 已知问题

当前版本主链路（解析 + 下载）稳定可用，但仍有以下已知项，将在后续版本逐步完善：

- **界面布局**：个别页面在窗口缩放时布局尚不完全理想。
- **配置持久化**：部分设置项在极端情况下可能存在保存不一致，重启后以后台配置为准。
- **抖音兜底解析**：依赖本机安装的 Chrome / Edge；无法解析时请确认浏览器已就绪。
