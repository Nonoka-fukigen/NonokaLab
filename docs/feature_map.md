# Nonoka Lab 功能地图

> 本文件是 Nonoka Lab 的功能地图，帮助用户快速了解每个模块的作用。详细架构见 architecture.md，插件开发见 plugin_development.md。

## Core 核心

| 模块 | 类型 | 说明 |
|------|------|------|
| 事件总线 | 核心 | 插件间通信 |
| 服务定位器 | 核心 | 插件同步调用 |
| 插件管理（Core） | 核心 | 扫描/加载插件 |
| 配置管理 | 核心 | 读写配置文件 |
| 日志系统 | 核心 | 异步分层日志 |
| 注册表自清洁 | 核心 | 自启键自管理 |

## 基础插件

| 插件 | 类型 | 说明 |
|------|------|------|
| 插件管理器 | 基础 | 加载/卸载插件 |
| 设置页 | 基础 | 所有设置 UI |
| 系统托盘 | 基础 | 后台运行与退出 |
| 组件管理器 | 基础 | 管理 ffmpeg 等组件 |
